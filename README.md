# Krapie Tap

## How do I install these formulae?

`brew install krapie/tap/<formula>`

Or `brew tap krapie/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "krapie/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
